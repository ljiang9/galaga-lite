# galaga-lite

迷你 Galaga 克隆：敌机编队左右摇摆、定时俯冲攻击，击落俯冲中的敌机有双倍分，
还有概率掉落**双打机**（双排子弹）。纯 Python 标准库，无第三方依赖。

## 玩法

- `a` 左移 / `d` 右移 / `s` 开火（冷却 4 帧）
- 敌机编队 3 行 × 8 列，每 40 帧派一架俯冲攻击
- 俯冲中的敌机分值翻倍；击落它有 30% 概率获得双打机（被击中则失去）
- 3 条命，清光敌机获胜

## 运行

```bash
python3 -m galaga_lite            # 交互模式（需要终端，逐行输入命令）
python3 -m galaga_lite --auto     # 自动演示：AI 躲避 + 射击，800 帧
python3 -m galaga_lite --auto --frames 2000 --seed 42
```

示例输出：

```
自动演示结束：失败，得分 300，剩余敌机 22，生命 0，帧数 364
```

## 限制（诚实声明）

- 没有实时键盘输入：交互模式是回合制"每行一个命令"，不是真正的街机手感
- `--auto` 的 AI 很弱，经常打不赢，这是演示不是最优解
- 文字渲染，无图形、无音效
